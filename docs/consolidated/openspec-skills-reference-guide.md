## 🚀 **Quick Start Guide Universal**

### **1. Escolher sua Stack**
```bash
# Consultar matriz completa de stacks
open .agents/skills/docs/guides/fullstack-stack-matrix.md

# Exemplo: C# + Angular + Android
STACK_BACKEND="csharp"
STACK_FRONTEND="angular"
STACK_MOBILE="android"
```

### **2. Bootstrap do Projeto**
```bash
# Backend C#
./.agents/skills/scripts/config-project-cs.sh --name "meu-projeto"

# Frontend Angular
./.agents/skills/scripts/config-project-angular.sh --name "meu-projeto"

# Mobile Android
./.agents/skills/scripts/config-project-android.sh --name "meu-projeto"

# Ou usar skill integrada
Skill: config-project-fullstack
Prompt: "Bootstrap projeto com backend C#, frontend Angular e mobile Android"
```

### **3. Criar Bounded Context**
```bash
# 1. Documentação do BC
cp .agents/skills/docs/templates/bounded-context-documentation-template.md \
   docs/bounded-contexts/BC-XXX-nome-do-bc.md

# 2. Backlog do BC
cp .agents/skills/docs/templates/bounded-context-backlog-template.md \
   docs/backlogs/BC-XXX-backlog.md

# 3. Validar estrutura
./.agents/skills/scripts/validate-advanced-dependencies.sh --new-bc BC-XXX --stack "$STACK_BACKEND"
```

### **4. Criar Tasks OpenSpec (Exemplos por Stack)**

