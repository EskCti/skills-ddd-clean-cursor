- `Domain/Base/ValueObject.cs`
- `Domain/Results/Result.cs`
- `Application/UseCases/IUseCase.cs`
- `Domain/Repositories/IRepository.cs`
- `Domain/ValueObjects/Email.cs`
- `Domain/ValueObjects/Name.cs`
- `Domain/ValueObjects/Id.cs`
